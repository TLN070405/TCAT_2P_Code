CODE DESCRIPTION
----------------
The code is split across four files. io_helpers.h implements write_all, read_all, send_all, and recv_all — each loops until every byte is moved, handling partial writes and reads for both files and sockets. endian.h implements hton64 and ntoh64 for 64-bit byte swapping, and float_to_net and net_to_float which reinterpret a float's bits as a uint32 to safely byte-swap it. payload.h defines the Payload struct which holds a mix of fixed-size fields and heap-allocated variable-length fields — an int array and a string. It uses a callback pattern with payload_put and payload_get so the same serialization logic serves both file and socket destinations without duplication. The four convenience wrappers payload_write, payload_read, payload_send, and payload_recv call through to those core functions. main.c builds a test payload and runs two demos — one writing to a binary file and reading it back, one forking into a client and server communicating over a loopback socket on port 9100.
